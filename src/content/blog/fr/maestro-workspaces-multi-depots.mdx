Travailler sur plusieurs dépôts à la fois sans basculer vers un monorepo : c'est le problème que Maestro résout. Cet article explique l'approche, et pourquoi elle compte encore plus depuis que des agents IA lisent notre code.

## Le coût caché du multi-dépôts

<Callout type="note" title="Plan">
  Cloner, synchroniser, retrouver le bon état : ce qu'une équipe perd chaque jour.
</Callout>

## Sparse-checkout et worktrees

```bash
git sparse-checkout set apps/api packages/shared
git worktree add ../feature-x feature/x
```

<Callout type="note" title="Plan">
  N'exposer que le code nécessaire, et plusieurs branches en parallèle sans recloner.
</Callout>
